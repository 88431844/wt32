# 群晖存储池页面布局设计

## 目标

调整 480 x 320 屏幕上的群晖 NAS 页面，使四个存储池充分利用顶部标题移除后释放的空间，完整显示多位容量数据，并在底部指标区加入群晖 IP 地址。

## 页面结构

- 保留现有 32 像素顶部导航栏。
- 删除 NAS 内容区中的“群晖 在线 4 个存储池”标题及对应状态文字。
- 288 像素高的 NAS 内容区由四个等高存储池行和一个双行底栏组成，只保留 4 像素外边距与行间距。
- 四个存储池行从内容区顶部开始排列，底栏延伸到内容区底部，填满原标题和原底部空白占用的空间。

## 存储池行

每行采用已确认的 A 方案：

1. 左侧显示状态实心圆和固定名称 `存储池1` 至 `存储池4`，不再显示 `池 1 Volume 1`。
2. 第一行右对齐显示 `已用 <used> / 总计 <total>`。
3. 第二行使用完整可用宽度右对齐显示 `剩余 <free>`。
4. 底部保留现有已用/剩余比例条。

容量文本使用独立的宽标签和右对齐方式，不依赖短数字宽度。设计至少容纳 `已用 24.1T / 总计 36.4T` 与 `剩余 887.0G`，不会因三位及以上数字而截断。

## 状态显示

- `正常` 仅显示绿色实心圆，不显示状态文字。
- 修复、迁移、扩容、创建、同步、校验、组装等进行中状态显示黄色实心圆。
- 降级显示黄色实心圆，故障显示红色实心圆。
- 未知或缺失状态显示灰色实心圆。

状态颜色复用当前主题调色板，主题切换后同步刷新。

## 底部指标区

底栏改为两行固定布局：

- 第一行依次显示 `IP <nas_host>`、`CPU <percent>`、`内存 <percent>` 和 `温度 <value>`。
- 第二行显示上传和下载速率，并为最长的常见格式保留整行宽度。
- 群晖未配置地址时显示 `IP --`；其他指标继续沿用现有缺失值规则。

IP 使用监控快照中的 `nas_host`，不重复使用顶部导航栏中的本机 Wi-Fi 地址。

## 实现边界

- 只调整 `dashboard_ui.c` 的 NAS 控件结构、更新逻辑和对应 UI 合约测试。
- 不改变 SNMP 采集流程、存储池数量上限、容量单位格式、主题或刷新机制。
- 不修改 PVE 页面、设置页面或顶部导航栏。

## 验证

- UI 合约确认标题被移除、固定存储池名称、状态圆点、群晖 IP 和双行底栏均存在。
- 使用多位容量示例验证 `剩余 887.0G`、两位 TB 总量以及最长网络速率均不被裁切。
- 运行现有 Dashboard UI 合约测试，并在可用的 LVGL/ESP-IDF 构建环境中执行编译检查。
